# Policy Engine (Agent Personalities)

The Policy Engine serves as the behavioral "Brain" of the framework, dictating *how* the physical modules operate by simulating distinct human archetypes.

### Core Features

#### 1. Mathematical Shifting
Instead of using fixed variables for typing speed or mouse movement, the Policy Engine hot-swaps the underlying math. A "Methodical" personality will type slowly with straight mouse movements, while a "Hyperactive" personality will type erratically with chaotic mouse swoops.

#### 2. Dynamic Fatigue Scaling
It applies custom stamina pools. Some personalities start typing very fast but quickly burn out, drastically lowering their Words Per Minute at the end of a long paragraph. Other personalities type at a slow but unwavering pace.

#### 3. Typo Multipliers
It scales the probability of mistakes based on the archetype. "Distracted" profiles make frequent typos and constantly trigger the backspace-correction loop, while "Professional" profiles rarely make mistakes.

#### 4. Anti-Fingerprinting
Because the behavior shifts entirely depending on which personality is loaded, anti-bot security algorithms cannot build a recognizable mathematical profile of the agent over time. The agent acts like dozens of different humans instead of one identical script.

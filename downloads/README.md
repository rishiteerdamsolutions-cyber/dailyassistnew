# Release packages

Place your distributable zips here before shipping:

| File | Contents |
|------|----------|
| `AHA-mac.zip` | Full project + `start_companion.command` + `INSTALL.md` |
| `AHA-win.zip` | Full project + `start.bat` + `INSTALL.md` |

Users download from `/download` → links to `/downloads/AHA-mac.zip` and `/downloads/AHA-win.zip`.

Build tip: zip the repo excluding `.venv`, `.env`, `*adminsdk*.json`, and `.git`.
